# Licence certificates for borrowed material

Keep the proof here, so a claim on the recording can be answered in one link.

| File | What it covers | Where it came from |
|---|---|---|
| `echoes-of-lumen-pixabay.pdf` | The club music, "Echoes of Lumen" by Lumen Sound | Download it from the track's Pixabay page, under the download dialog: **Download license certificate** |

The Pixabay Content Licence allows commercial use and does not require credit, but this track is
registered with YouTube Content ID. If the recording is ever claimed, the certificate clears it.
